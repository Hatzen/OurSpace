# OurSpace

An online MMORPG in Minecraft Graphics, so that everything can be destoried somehow blockwise, or maybe use complexer polygons? 

Should be similar to Nomans Sky, Star Citizen with PvP. Each player is unique but has normal tasks like fisher, police, soldier, commander, politician etc. 
If you die you just start fromn beginning. When people stop playing for more than 24h bots should take over. 
Gameplay should provide many possible gaming mechanics like in gta5 online. but it should be a fluent world. 
Simple Tasks like mining, farming but also fights like battlefield, where each soldier gets commands like in ghost recon by a commander being at a very different planet or place but seeing a digital mini map hologram of the frontline, he is giving commands where to attack as he sees where enemy is moving. Capture the flag (secret informations) for your fraction.  There should be different space fractions and species which have different political organisations and structures that will change by votes etc.  A bit like Star wars republic or star treks fractions.  

We dont want to have more than 32 players at one place, so usually it should be filled with robots or ais doing tasks. Other Bots and Players shouldnt be able to be differntiated by behaviour or tasks.
